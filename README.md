# udemy-complete-javascript

Source code of the challenges and projects from the Udemy course [The Complete JavaScript Course 2024: From Zero to Expert!](https://www.udemy.com/course/the-complete-javascript-course/) by Jonas Schmedtmann. The course repository is [jonasschmedtmann/complete-javascript-course](https://github.com/jonasschmedtmann/complete-javascript-course), and my certificate is [here](https://www.udemy.com/certificate/UC-6ed688b1-1953-4b2b-bb70-f4aeaa502caa/).
